# Eminence 2026 – College Fest Registration Portal

A fully responsive, multi-page web application designed for **VIT Vellore's annual cultural fest (April 28–30, 2026)**.
This portal allows students to explore events, register online, purchase merchandise, and access complete fest information — all built using **HTML, CSS, and JavaScript (no backend)**.

## Features

* **Live Event Search & Filtering**

  * Filter by category, fee, day, time, and team size
  * Real-time updates using JavaScript

*  **Dynamic Event Cards**

  * 12 events rendered from JavaScript data
  * Includes events like Hackathon, Robo Wars, Battle of Bands, etc.

*  **Event Detail Modal**

  * View rules, description, slots, and prizes

* **Multi-Step Checkout System**

  * Step 1: Event Selection
  * Step 2: Personal Details
  * Step 3: Payment Summary
  * Step 4: Confirmation

* **Merchandise Store**

  * Add-to-cart system with items like T-shirts, hoodies, caps, etc.

* **Live Countdown Timer**

  * Countdown to fest opening (April 28, 2026)

* **Scroll Animations**

  * Smooth reveal effects using IntersectionObserver

* **Schedule Page**

  * Complete 3-day event timetable

* **FAQ Section**

  * Accordion-style expandable questions

* **Sponsors Page**

  * Tiered sponsor display (Platinum, Gold, Silver)

* **Fully Responsive Design**

  * Works across mobile, tablet, and desktop

## How to Run the Project

1. Download or clone the repository:

   ```
   git clone https://github.com/your-username/eminence-2026.git
   ```
2. Open `index.html` in your browser

No installation or backend required

---

## Working Flow

1. User lands on homepage → views countdown & highlights
2. Navigates to events → filters & selects event
3. Opens event modal → clicks register
4. Completes multi-step checkout
5. Receives confirmation with unique ID

## Advantages

* No backend required – runs entirely in browser
* Fast performance (no frameworks)
* Scalable structure using JS data arrays
* Real-world UX simulation (like Unstop/Devfolio)
* Mobile-friendly

---

## Limitations

* No database (data not stored permanently)
* No real payment gateway
* No authentication system
* Static event data
* No email functionality
